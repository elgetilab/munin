# Fresh lab cases (checks against tuning)

27 S1 cases: the nine seeded families (3PL, 4PL, 5PL, Michaelis-Menten,
competitive inhibition, Morrison, one- and two-phase decay, standard curve)
with seeds 6, 7 and 8, generated by `fixtures/lab/generate/s1.py` AFTER
`labkit` was frozen (commit 6900e5f) and not inspected before the Phase 4
run (docs/agent-track/LAB-PHASE3-PLAN.md). Kept outside `fixtures/lab/` so
the default runs do not pick them up. Run with
`--fixtures fixtures/lab_fresh`. The S2, S3, S5 and S6 generators are not
seeded, so they have no fresh variants.

21 S8 (EPR) cases, `s8_*_f1`: the S8 generator with `s8.VARIANT = 1`,
which redraws every case's parameters (field, linewidth, g, distances,
widths, background, noise) from a separate seed; variant 0 is the committed
S8 suite, byte for byte. Generated after `labkit` 0.2.0 (`labkit.epr`,
commit 15815f8) was frozen, for an S8 check against tuning
(docs/agent-track/EPR-PLAN.md). Run with `--fixtures fixtures/lab_fresh
--suite S8`.

21 more S8 cases, `s8_*_f2` (`s8.VARIANT = 2`), generated after `labkit`
0.2.1 was frozen (commit 6e64286): round 2 (docs/agent-track/LABKIT-015-PLAN.md)
was tuned on the `_f1` failures, so `_f2` is the untuned check for it.
Checked with DeerLab 1.2.0 and the independent CW analysis, not with labkit.

21 more, `s8_*_f3` (`s8.VARIANT = 3`), generated after `labkit` 0.2.2 was
frozen (commit ff02761): LABKIT-018 (docs/agent-track/LABKIT-018-PLAN.md) was
tuned on the `full-lk17` failures, so `_f3` is the untuned check for it. The
independent CW analysis recovers all 11 CW truths; DeerLab 1.2.0 recovers the
DEER truths (mean, modulation depth, t0, concentration, bimodal components;
for `short_trace_f3` the Gaussian fit gives 3.09 vs 3.10 nm main distance).

5 S8 powder / fit cases, `s8_cw_{cu_powder,nitroxide_rigid,rhombic,radical_fit,units}_f1`
(`s8.VARIANT = 1` with `s8_powder.build` only), generated 2026-11-26 after
LABKIT-019 (labkit 0.3.1) was frozen (docs/agent-track/LABKIT-019-PLAN.md):
the untuned check for that round. These five had no earlier fresh variant,
so `_f1` is unseen. VARIANT 0 of the same call reproduces the committed
cases byte for byte.
