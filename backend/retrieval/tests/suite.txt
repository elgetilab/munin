# Test tiers for backend/retrieval/tests, read by run_suite.py.
#
# Every test_*.py and smoke_*.py in this directory MUST have a line here:
# run_suite.py refuses to run (exit 2) while a file is unclassified, so a new
# test cannot silently fall out of CI.
#
# Columns: file, tiers (comma-separated), optional runner.
#
#   hermetic  runs with --network none: no Qdrant, Neo4j, vLLM, encoder
#             weights or internet. GitHub CI runs this tier on every push
#             (.github/workflows/ci.yml, job retrieval-tests).
#   live      needs the real Qdrant index and encoders on munin-network, but
#             NOT vLLM (the nightly run sits inside the 02:00-06:00 vLLM
#             maintenance window). Run nightly on hugin by
#             backend/scripts/ci/nightly_live_tests.sh. A file in both tiers
#             has a hermetic half and a live half that SKIPs (or stubs) when
#             the services are absent.
#   manual    hits vLLM and live web search (paid quota); never scheduled.
#
#   runner `pytest`: the file needs pytest fixtures or parametrize, so it is
#   run with `python -m pytest` when pytest is importable. Without pytest
#   (the production image) it runs under plain python and SKIPs what it can't.
#
