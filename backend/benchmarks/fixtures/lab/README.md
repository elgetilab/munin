# Lab-analysis fixtures

Inputs and truth for the lab-analysis eval suites
(`docs/agent-track/LAB-PHASE1-PLAN.md`). The runner is
`munin_bench/labanalysis/` (`python -m munin_bench.labanalysis.run --help`).

```
cases/<case id>/   case.json (prompts, checks), truth.json, the input files
generate/          the seeded generators that write cases/
nist/raw/          the 27 NIST StRD nonlinear reference files, verbatim
userdata/          the user's own data the S6 cases are built from
SHA256SUMS         every file under cases/
```

Regenerate with `python fixtures/lab/generate/build.py` and verify with
`--check`. `tests/test_labanalysis.py` regenerates into a temp dir and
compares (data byte-identical, reference values within 1e-4), runs an oracle
answer through every case, and checks that the naive answer to each trap fails.

## Provenance

Every `case.json` carries a `provenance` line.

- **Synthetic** (S1 fits and traps, S2 except NIST, S3, S5, S6 titration and
  relaxation): generated by `generate/*.py` from a fixed seed. Data is written
  with fixed precision and read back; reference values are fitted to what was
  written, then rounded to 6 significant digits. Each S1 truth also keeps the
  generating parameters for coverage across seeds.
- **Instrument formats** (S2) are mimics built from the documented layouts
  (header blocks, encodings, locales, plate grids), not files from the
  instruments. The Bruker experiment is written directly (acqus, int32 FID
  with GRPDLY 76, procs) and was checked with nmrglue in the sandbox image:
  its standard chain recovers every shift within 0.001 ppm. Real exports go
  in the held-out set.
- **NIST StRD** (`nist/raw/`): public domain, U.S. National Institute of
  Standards and Technology, Statistical Reference Datasets. The case CSVs copy
  the x and y strings verbatim; the certified values stay out of the upload.
- **User data** (`userdata/`): the user's repositories, copied with
  permission and relicensed with this repository (Apache-2.0).
  `noesy_ceritinib/` is `varghele/1H1H-NOESY` at 0e2b517, `example/`
  (TopSpin integral exports, Ceritinib in POPC); `order_2h/` is two files of
  `varghele/GNN2H` at d030950, `data/2H_data/` (the 2IBU set at 303 K). The
  reference values are recomputed by `generate/s6.py`, never taken from the
  old scripts' outputs.

## Grading notes

- Numbers are read from `results.json`, which every prompt asks the model to
  save with named keys (fallback: the last fenced JSON block of the answer).
- Fit cases grade the estimate against the least-squares optimum of the
  written data and the interval against the reference Wald interval
  (`ci_close`, bounds within 25% of its width).
- Missing values must stay missing: `numeric_map` fails when a value is
  reported for a key whose truth is null (absent residues, saturated wells).
- S3 reads the sandbox figure manifest. Error bars drawn as plain lines
  (seaborn 0.12 and later) are not recognised as error bars, so the SD/SEM
  checks need matplotlib errorbar containers.
- Deferred to Phase 1b: the 31P lineshape case (its reference needs a
  lineshape simulator, which is `labkit` work) and MicroCal `.itc` (needs a
  verified format sample or the pytc demos with a checked licence).
